# Instruções — Registro de Sessões Claude

O arquivo começa com `.` para aparecer primeiro. Não é um registro: é a instrução de como preenchê-los. Nunca
apague nem renomeie.

Ao final de uma sessão de trabalho, criar **um arquivo por sessão** (não por tarefa):
`AAAA-MM-DD-slug-curto-do-assunto.md` (data de hoje; slug em kebab-case, português, sem acento).

Estrutura obrigatória:

```markdown
# Título curto e específico

**Data:** AAAA-MM-DD

## Resumo
O que motivou a sessão e o que foi entregue, em linguagem simples.

## Mudanças de negócio
O que muda para quem usa (admin do Ágora, líder de entidade). Se for só técnico: "Nenhuma — mudança técnica/interna."

## Mudanças técnicas
Prosa: o que mudou, decisões, trade-offs e o porquê.

## Arquivos alterados
Por área (nova/modificada/removida), com caminho relativo à raiz.

## Banco de dados
Migrations, seed, escritas. Omitir se não houve.

## Deploy
Para onde e quando. Omitir se não houve.

## Pendências / próximos passos
Omitir se não houver.
```

Regras: nunca dado sensível (senhas, tokens, connection strings, e-mails reais); português direto; não reescrever
registros antigos (cada arquivo é um snapshot).
